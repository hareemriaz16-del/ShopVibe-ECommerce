# ShopVibe — Interactive E-Commerce Frontend Web App

ShopVibe is a modern, responsive e-commerce web platform built using HTML5, CSS3, and JavaScript (ES6+).

## 🚀 Features Implemented (Till Module 2)

### Module 1: UI Layout & Responsive Structure
- Semantic HTML5 document structure.
- Modern CSS Flexbox Navigation Bar with logo, search box, and cart badge counter.
- Hero banner section showcasing featured announcements.
- Category filter button layout.
- Fully responsive CSS Grid layout for displaying products.

### Module 2: Dynamic Product Grid & Data Rendering
 Array-based Mock Product JSON Data structure.
 Dynamic DOM rendering of product cards using JavaScript (`app.js`).
 Integrated high-quality product images, titles, category badges, prices, and interactive 'Add to Cart' buttons.

## 🛠️ Tech Stack
 **Frontend:** HTML5, CSS3, JavaScript (DOM Manipulation)
 **Version Control:** Git & GitHub
